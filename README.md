# 월급연구소 PAYLAB

급여·세금·퇴직·수당을 계산하고, 금액과 함께 계산 과정을 보여주는 직장인 계산기입니다. https://paylab.kr

## 계산기

- 월급·연봉 실수령액 (2026년 1월 ~ 2027년 6월 급여)
- 연말정산 환급액 (2026년 귀속, 2027년 1~2월 정산)
- 시급·최저임금 월 환산
- 퇴직금
- 실업급여(구직급여)
- 연차 발생일수
- 주휴수당
- 휴업수당

계산기마다 고유 URL이 있고, 계산은 브라우저 안에서 합니다. 입력한 급여와 날짜는 서버에 저장하지 않습니다.

## 기준 데이터

현재 버전은 `2026.11.21`입니다.

| 파일 | 내용 |
|---|---|
| `lib/policy.ts` | 연도별 최저임금, 4대보험료율, 구직급여 상·하한 (`POLICY_2026`, `POLICY_2027`) |
| `lib/year-end-policy.ts` | 2026년 귀속 연말정산 세율·공제 기준 (`YEAR_END_2026`) |
| `lib/calculations.ts` | 급여·퇴직·수당 계산 함수 |
| `lib/year-end-tax.ts` | 연말정산 계산 함수 |
| `lib/site-content.ts` | 계산기 설명, 연도 비교표, 업데이트 기록 |

### 2027년에 바뀐 값

- 최저임금: 시급 10,320원 → 10,700원 (월 209시간 2,236,300원)
- 국민연금 근로자 부담: 4.75% → 5.0%
- 장기요양보험: 소득 대비 0.9448% → 0.9994% (건강보험료의 13.90%)
- 건강보험 근로자 부담: 3.595% 동결

### 2027년 적용 근거를 추가로 확인할 항목

2026-11-21 확인 기준입니다. 근거 문서와 반영 상태는 `lib/policy.ts`에 기록하고 `/standards`에 표시합니다.

- 건강보험료 상·하한과 고용보험료율은 현행 고시·시행령 값을 적용합니다. 고용보험료율 인상은 입법예고까지 확인했습니다.
- 구직급여는 2027년 적용 상한을 확인할 때까지 일액과 총액을 모두 하한 기준으로 표시합니다.
- 국민연금 기준소득월액은 공단이 안내한 2027년 6월까지만 급여 계산에 적용합니다.
- 소득세는 현행 기본세율·공제로 추정합니다. 국회에 제출된 정부안을 계산식에 반영하려면 의결·공포와 적용 시기 확인이 필요합니다.

### 2026년 귀속 연말정산에서 2025년 귀속과 달라진 점

- 자녀세액공제 대상: 2016년 12월 31일 이전 출생 자녀 (2017년생은 아동수당 수급 기간 동안 제외)
- 신용카드 기본 한도: 자녀 1명당 50만원(총급여 7,000만원 초과는 25만원)씩, 2명까지 상향
- 고향사랑기부금: 10만~20만원 구간 공제율 15% → 40%

공식 출처는 사이트의 `/standards` 페이지와 계산기별 근거 자료 목록에 있습니다.

## 결과의 한계

법적 확정액이 아닌 참고용 예상치입니다.

- 실수령액의 소득세는 국세청 간이세액표 조회값이 아니라, 1년 치 세액을 단순 계산해 12로 나눈 값입니다.
- 4대보험은 회사가 신고한 기준소득월액·보수월액과 정산에 따라 실제 고지액과 다를 수 있습니다.
- 연말정산 계산기는 주택담보대출 이자, 중소기업 취업자 감면 등 일부 항목을 다루지 않고, 부양가족 요건을 판단하지 않습니다.

## 로컬 실행

Node.js 22.13 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

## 검증

```bash
pnpm test   # 빌드 후 계산·보안·화면 렌더링 테스트
pnpm lint
```

테스트는 틀리기 쉬운 경계를 고정합니다. 국민연금 6월/7월, 2026년 12월/2027년 1월 요율 변경, 고시 전인 달의 입력 거부, 월말 퇴직금 역산, 1년 경계 연차, 단시간 근로자의 구직급여 하한, 연말정산의 공제 문턱(총급여의 25%, 3%)과 한도 등입니다.
